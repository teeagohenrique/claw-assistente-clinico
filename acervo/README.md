# Acervo — materiais de origem

Coloque aqui os textos autorais do Dr. Responsável que servirão de base para o
**Acervo Psicoeducativo & Guia Clínico**.

## Formatos aceitos

- `.pdf` (com texto selecionável; PDFs digitalizados precisam de OCR antes)
- `.docx`
- `.txt`
- `.md`

## Exemplo de organização

```
acervo/
├── Sobriedade Emocional.pdf
├── 10º Passo - Guia Prático.docx
└── artigos/
    └── ansiedade-e-autocuidado.md
```

## Importante

- Os arquivos desta pasta **não são versionados** no Git (materiais autorais e
  arquivos grandes). O que fica versionado é apenas este README.
- A ingestão grava os blocos e embeddings no Supabase, não no repositório.
- PDFs escaneados (imagem) não têm texto extraível; aplique OCR antes.
